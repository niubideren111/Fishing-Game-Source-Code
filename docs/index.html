常见问题

公开客户端文件使用什么语言？

当前公开配置和逻辑文件主要为 JavaScript，服务器片段为 C++；产品说明采用 Cocos 客户端定位。

想了解炮台系统从哪里开始？

先阅读 BYCannonConfig.js，再对照等级、列表和皮肤配置；通信流程查看协议文档。
